# Research-Assignment-1
Hand written research paper covering the fundamentals of data analytics and data science.
This is an indepth research assisgnment studying the fundamentals of data and how data is explored into buildng operational systems and providing business with insights to make well informed decisions. 
The assisgnment investigates the use of data in artificial intelligence (AI) and machine learning (ML) which is currently a globaly emerging market. The assignment digs deeper into how data interacts with the various subsets of ML and AI to leaarn and perform a desired function. 
It also explores the intermediary (agent like) tools used in Ml and AI such as Application Programming Interface, Tools, and development concepts. These are facilitators of data and the assignment engages their importance and the value they add in working with data to make business decisions. 
Lastely, the assignment studies data ethics and governance, providing a framework for the uses of data and which guides build  the arameters of which the data must be used within.
